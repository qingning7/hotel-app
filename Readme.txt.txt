20260205：这里是我建的一个简单的框架，admin文件夹是管理端，user文件夹是用户端，两者现在的数据交互是用localstorage做的。运行过程如下：
（1）进入vscode之后新建终端，输入“cd admin-frontend”进入管理员文件夹，第一次使用需要安装依赖文件，输入“ npm install”,下载完成之后，输入“npm start”从浏览器打开页面，然后用商户端的账号登入就能输入酒店信息并提交，用管理员的账号登录就能审核酒店信息，，管理员点用过之后，酒店信息就会存储在storage里面。
（2）然后新建一个终端，输入“cd user-frontend”进入用户文件夹，，依然是跟上面一样安装依赖文件之后打开，进入页面后就能看到酒店信息并且预订。
